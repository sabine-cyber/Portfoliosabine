# Portfolio — Sabine Loréate GBECHI

Site vitrine personnel : réseaux & installation, développement, compétences, projets, contact.

## Structure
- `index.html` — la page
- `style.css` — les styles
- `script.js` — menu mobile + animations d'apparition au scroll
- `images/` — photos (portrait, chantier réseau) et visuels de compétences

## Utilisation
Ouvrir `index.html` dans un navigateur, ou héberger le dossier tel quel (GitHub Pages, Netlify, etc.).

### Publier sur GitHub Pages
1. Pousser ce dossier dans un dépôt GitHub.
2. Dans les réglages du dépôt → Pages → Source : branche `main`, dossier `/root`.
3. Le site sera disponible à `https://<ton-compte>.github.io/<nom-du-repo>/`.
